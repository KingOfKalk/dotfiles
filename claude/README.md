# Claude

Clones [`KingOfKalk/claude`](https://github.com/KingOfKalk/claude) to copy `CLAUDE.md` into `~/.claude`, then adds the `anthropics/claude-plugins-official` marketplace and installs the `superpowers` plugin via the `claude` CLI.

`test.sh` verifies `~/.claude/CLAUDE.md` and, if `claude` is installed, that the `superpowers` plugin is present.
